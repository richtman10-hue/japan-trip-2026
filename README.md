# Japan–Korea 2026 — V46

עדכון V46 מתקן את שגיאת האתחול ב־V45 שגרמה לכך שהאפליקציה הציגה כותרת בלבד ללא תוכן.

## מה השתנה
- תוקן סדר האתחול של מילון תיאורי האתרים: התיאורים הנוספים מתווספים רק לאחר הגדרת `DESCRIPTIONS`.
- נשמר תוכן המסלול וההחלטות שהופיעו ב־V45, לרבות מסלול האקונה, יום המעבר דרך קוואגוצ'יקו ומאטסומוטו, אראשיאמה, שוק נישיקי, פרטי רכבת Nozomi 127, והאפשרויות בהירושימה ובמיאג'ימה.
- עודכן מספר הגרסה המוצג באפליקציה ובתיעוד ל־V46.

## קבצים
- `index.html` — האפליקציה.
- `README.md` — תיעוד הגרסה.

## העלאה ל־GitHub Pages
החליפו במאגר את `index.html` ואת `README.md` בקבצים שבחבילה, ואז בצעו Commit. השאירו קבצים נוספים שכבר קיימים במאגר (למשל תמונת הלוגו) ללא שינוי.

## בדיקות
תחביר JavaScript נבדק. יש לבדוק את האתר לאחר הפרסום בדפדפן כדי לוודא שהתוכן נטען כראוי.
