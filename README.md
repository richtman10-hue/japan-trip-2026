# Japan–Korea 2026 — V36

עדכון V36 כולל את התוספות שנצברו עד 23.10.2026. הגרסה אינה מפורסמת באתר החי; יש להעלות את הקבצים למאגר GitHub כדי לפרסם.

## שינויים עיקריים
- נוספה לשונית היום תיבת "לו״ז שעתי מוצע" לכל יום מ-31.10 עד 24.11, כולל זמני מעבר, ארוחות, פעילויות וחלופות.
- 4.11: הוסרו Ginza 4-chome Crossing ו-Wako Clock Tower מהמסלול, מהמפה ומהקישורים.
- 5.11: נוספה תצפית Shibuya Hikarie Sky Lobby בקומה 11 בסוף הסיור עם בועז, בכפוף לשעת הסיום ולגישה בפועל.
- 6.11: נשמר מסלול Asakusa–Kappabashi–Ueno–Ameyoko–Akihabara, עם אפשרות חלופית להשתתף בערב המקדים של פסטיבל המגרפות.
- 7.11: היום מתמקד בשינג׳וקו; נוספו פסטיבל Hanazono Shrine Tori-no-Ichi, Kabukicho/Godzilla Road, ראש גודזילה בבניין Toho, וטעימת Yakitori ב-Omoide Yokocho. הוסרה Ginza מהיום.
- Yayoi Kusama Museum נוסף כ-Plan B ליום גשום בטוקיו. המוזיאון פתוח חמישי–ראשון 11:00–17:30 ודורש כרטיס מקוון מראש לחלון כניסה של 90 דקות.
- חודדו הערות קניות: ABC-MART/GRAND STAGE מוגדר לרכישת נעלי ספורט, בדגש על New Balance 9060.
- נשמרו המלצות הקניות וההכנות הקודמות: JINS, Onitsuka Tiger, סכין Santoku ואביזרי השחזה, MUJI באוסקה, Don Quijote, Bic Camera, Global Blue, Airalo eSIM והנחת Senior מעל גיל 65.
- חיפוש זכוכית המגדלת ממשיך להוביל ישירות לכרטיס ההמלצה הרלוונטי כשיש התאמה.
- נשמרו פרטיות כרטיסי הרכבת וקודי ה-QR; הם אינם מוצגים באפליקציה הציבורית.
- נשמרו ממירי מטבע, כולל KRW לשקל ולדולר עם אפשרות לרענון שער.

## שעות פתיחה
לוחות הזמנים השעתיים הם הצעות תכנון. שעות פתיחה, כניסה אחרונה, סגירות מיוחדות וזמינות מופעים עשויות להשתנות; יש לבדוק את המקור הרשמי סמוך לביקור.
