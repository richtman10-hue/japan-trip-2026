# Japan 2026 V34

עדכון V34 כולל את כל התוכן הקודם של V33, ובנוסף:
- חיפוש בזכוכית המגדלת: כותרות התוצאות הן קישורים לחיצים.
- בחירה בתוצאת המלצה, למשל "JINS – משקפיים", מעבירה ללשונית ההמלצות ומגלילה ישירות לכרטיס ההמלצה המתאים.
- הכרטיסים בלשונית ההמלצות קיבלו מזהים ייחודיים כדי לאפשר ניווט מדויק מתוך החיפוש.
- מספר הגרסה עודכן ל-V34.

הגרסה נשארת ללא PWA וללא Service Worker.
