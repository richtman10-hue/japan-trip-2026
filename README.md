# Japan 2026 – GitHub Pages

גרסה מוכנה ל-GitHub Pages.

## חשוב
הגרסה הזו אינה כוללת מסמכים אישיים (אישורי מלונות, כרטיסי טיסה, הזמנות וכו') כדי שלא יהיו ציבוריים ב-GitHub Pages.

## העלאה ל-GitHub
1. צור Repository בשם: `japan-trip-2026`
2. העלה את כל הקבצים שבתיקייה הזו לשורש ה-Repository.
3. ב-GitHub פתח:
   Settings → Pages
4. תחת Build and deployment בחר:
   Deploy from a branch
5. Branch:
   `main` / `(root)`
6. Save

לאחר כמה דקות הכתובת תהיה בדרך כלל:
`https://<YOUR_GITHUB_USERNAME>.github.io/japan-trip-2026/`

## קיצור דרך באנדרואיד
פתח את כתובת האתר ב-Chrome → תפריט ⋮ → Add to Home screen / Install app.
