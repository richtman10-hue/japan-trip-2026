# Japan–Korea 2026 — V48

אפליקציית הטיול ליפן וקוריאה, 31 באוקטובר עד 24 בנובמבר 2026.

## מה חדש ב־V48
- כפתור **מפת יפן 26** מופיע בתחתית כרטיס היום, במקום **מפה כללית**.
- הוסר הכפתור הכפול לפתיחת רשימת המפה מתוך כרטיס **מפת היום**.
- נשמרו כפתורי הניווט היומיים והמסלולים לפי יום.
- קישורי Godzilla Road ו־Omoide Yokocho הוחלפו בקישורי חיפוש ממוקדים ב־Google Maps בעקבות שגיאות 502 באתר GO TOKYO.
- מטמון ה־Service Worker עודכן לגרסה V48.

## פרסום
יש להעלות למאגר GitHub את `index.html`, `sw.js` ו־`README.md` מתוך החבילה, ולהחליף את הקבצים הקיימים באותם שמות. `manifest.webmanifest` כלול לצורך השלמות אך אינו דורש שינוי.

**חשוב:** לא למחוק את קובצי האישורים, המסמכים, התמונות או התיקיות הקיימות. אין צורך להעלות מחדש את כל המאגר.

## בדיקות לאחר הפרסום
פתחו את האפליקציה אונליין, ודאו שמופיעה V48, בדקו את כפתור המפה ואת יום 7.11, ולאחר מכן סגרו ופתחו שוב במצב טיסה ו־Wi-Fi כבוי ובדקו פתיחת אישור מלון.

קישורים לאתרים חיצוניים ומפות Google דורשים אינטרנט, אלא אם הוכן תוכן מתאים מראש במכשיר.
